# Claw Meets Ball (web version)

Play in the browser: open this site's GitHub Pages link.

Grab the orange ball from the blue bin and drop it in the green bin. Deliver as many balls as you can in 60 seconds.

Controls: WASD / arrows move · Q / E lower / raise · Space open / close claw · R reset ball (−3 s) · C switch camera · Esc pause · H hide help

Offline copy: `download/ClawMeetsBall.html` is the whole game in one file. Download it and double-click it to play without internet.

Made with Godot 4.5.1 (official Web export). This web version is for playing and sharing; it was not used to collect experiment data.
